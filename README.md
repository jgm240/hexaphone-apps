# hexaphone-apps

Companion apps and content for [Hexaphone](https://github.com/jgm240/Hexaphone) (LineageOS 16.0 for the Nexus 10 / manta), fetched at runtime by the ROM's built-in **Hexaphone Store** app rather than bundled into the system image.

## Layout

- `bootscreen-app/` — the [Bootscreen](https://github.com/jgm240/Hexaphone/tree/main/packages/hexaphone/Bootscreen) app itself (`Bootscreen.apk`), installable from Hexaphone Store.
- `bootscreen/` — the boot animation presets Bootscreen offers: a `manifest.json` (id, display name, file, sha256, size) plus one `bootanimation.zip`-format `.zip` per preset, generated by [`vendor/hexaphone/art/gen_bootscreen_presets.py`](https://github.com/jgm240/Hexaphone/blob/main/vendor/hexaphone/art/gen_bootscreen_presets.py) in the main Hexaphone repo. Same rendering code as the ROM's own default boot animation, swept across a color x speed matrix.
- `updater-app/` — the [Hexaphone Updater](https://github.com/jgm240/Hexaphone/tree/main/packages/hexaphone/Updater) app itself (`HexaphoneUpdater.apk`), installable from Hexaphone Store. Replaces LineageOS's own Updater (dead since 2016) -- lists every [jgm240/Hexaphone release](https://github.com/jgm240/Hexaphone/releases) and downloads/verifies whichever one you pick, for installing or downgrading. Flashing is still manual, from recovery.

Every file Hexaphone Store downloads from here is hash-verified against the pinned `sha256` before it's used.
